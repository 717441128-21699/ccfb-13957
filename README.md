# 陶瓷碎片虚拟拼接工作台

面向文物修复的陶瓷碎片三维虚拟拼接工具：导入扫描网格 → 自动识别断口 → 按断面起伏与胎壁厚度变化配对 → 人工确认候选 → 整体联动拼合 → 对称补配缺口 → 器形测量与线图导出 → 网页三维展示。

## 技术栈

- **语言**：TypeScript（strict）
- **三维渲染**：原生 WebGL2（无重型 3D 依赖，离线可用）
- **配对计算**：Web Worker（ES Module Worker），主线程零阻塞
- **构建**：Vite 5
- **自检/造数**：Node + tsx

## 快速开始

```bash
npm install
npm run gen        # 生成破成 30 片（含扫描噪声）的合成陶罐
npm run selftest   # 端到端自检：缝隙、耗时、召回率
npm run dev        # 启动网页工作台
npm run build      # 类型检查 + 生产构建
```

打开浏览器后点「载入示例 30 片罐」→「分析断口」→「全自动配对」→「一键自动拼合全部候选」→「对称补配缺口」→「器形测量」。

## 核心算法（`src/core/`）

1. **断口识别与边缝分割**（`fracture.ts`）
   - 有表面标签时直接取 Fracture；无标签扫描件按顶点法向突变 + 距质心方向自动分类釉面/胎面/断口。
   - 断口按顶点邻接做连通域分割，一片碎片的 2~4 条边缝各自成为独立子断口。
2. **特征描述**（`descriptors.ts`）：简化 FPFH（α/φ/θ 三角度直方图，33 维），双向最近邻 + 互逆匹配生成 RANSAC 种子。
3. **胎壁厚度**（`geometry.ts`）：断口点到本片外壁/内壁最近点距离估计壁厚，并在断口切平面内求厚度梯度（对应"胎壁由厚到薄"的变化）。
4. **配对配准**（`matcher.ts`）
   - 三点 RANSAC 求刚体（含零位移先验，适配同坐标系扫描件）；
   - 点到平面 ICP 精修；
   - 厚度梯度一致性、逐点厚度相对误差、釉面/胎面朝向（防拼反）三重校验；
   - 粗筛：断口规模比、平均壁厚、全局空间一致性（防局部贴合的假边）。
5. **整体拼合**（`matcher.ts` + `global-icp.ts`）：并查集贪心生成树，接受一条边即把整组刚体变换串联（"接上一片整体跟着动"）；全局 ICP 沿生成树 Gauss-Seidel 传播，带步长上限与"必须降缝隙"回退保护。
6. **对称补配**（`fill.ts`）：现存外壁点估计器轴（回转对称度选轴），缺失区域按轮廓线回转重建，标签置为 Fill，渲染端青蓝换色。
7. **器形测量**（`measure.ts`）：轴系投影分带量口径/腹径/底径/通高，外轮廓与内置器形库（罐/瓶/钵/碗）归一化比对，导出半剖 SVG 线图与测量 JSON。

## 目录结构

```
src/
  core/        算法与数据结构（浏览器/Worker/Node 三端共用）
  worker/      Web Worker 入口
  webgl/       WebGL2 渲染器（标签着色、点选、编号精灵、轮廓线）
  ui/          页面主控与样式
  scripts/     造数、自检、冒烟测试（Node）
public/datasets/pot30.json   合成 30 片罐（27 片现存 + 3 片缺口）
```

## 数据与导入

- 示例数据由 `generator.ts` 生成：回转体器形 + 水平/垂直锯齿断口（高低起伏）+ 每顶点 0.08 mm 扫描噪声，单位 mm。
- 支持导入 OBJ 网格（`obj-loader.ts`，v/f，三角或四边面）；多文件即多碎片，无标签时自动做表面分类。

## 已知局限

- 配对依赖扫描件处于同一坐标系（结构光/手持扫描的常见输出）；碎片若被随意平移旋转，零位移先验失效，仍可由 RANSAC 收敛但召回下降。
- 测量在拼合累积误差较大时口径/底径会有偏差；腹径、通高与器形类别识别稳定。后续可引入全局束调整（pose graph optimization）进一步收敛。
- 器形库仅内置 4 个示范类型，可在 `measure.ts` 的 `VESSEL_LIBRARY` 扩充。
